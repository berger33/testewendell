# Projeto de fazenda adulto para Android

Jogo original de simulação de fazenda e vida comunitária, com temática ficcional de cannabis para público adulto. O projeto usa Godot 4 e GDScript. A direção visual busca cores vivas, silhuetas legíveis e animações expressivas, com arte e áudio próprios.

## Estado

F00 — Fundação do projeto. O repositório contém o plano de engenharia e um projeto Godot mínimo. Ainda não há gameplay nem build Android validada.

## Como começar

1. Abra `game/project.godot` na versão estável de Godot 4.
2. Execute a cena principal.
3. Leia `docs/engineering/plan.md`, `docs/engineering/architecture.md` e `docs/slices/F00.md` antes de implementar.
4. Cada fatia deve produzir uma issue, uma branch e um PR. No Arena Agent Mode, use uma sessão por fatia.
