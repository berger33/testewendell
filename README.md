# Projeto de fazenda adulto para Android

Jogo original de simulação de fazenda e vida comunitária, com temática ficcional de cannabis para público adulto. O projeto usa Godot 4 e GDScript. A direção visual busca cores vivas, silhuetas legíveis e animações expressivas, com arte e áudio próprios.

## Estado

F00 — Fundação do projeto. O repositório contém o plano de engenharia e um projeto Godot mínimo. Ainda não há gameplay nem build Android validada.

## Como começar

1. Abra `game/project.godot` na versão estável de Godot 4.
2. Execute a cena principal.
3. Leia o [manual de execução](docs/engineering/execution.md), o [plano](docs/engineering/plan.md), a [arquitetura](docs/engineering/architecture.md), os [contratos](docs/engineering/contracts.md) e a ficha da fatia antes de implementar.
4. Consulte o [catálogo de mecânicas](docs/gdd/mechanics-catalog.md), o [plano de QA](docs/qa/test-plan.md), as [regras de conteúdo e publicação](docs/engineering/content-and-release.md) e o [prompt pronto para F01](docs/engineering/start-arena-f01.md).
5. Cada fatia deve produzir uma issue, uma branch e um PR. No Arena Agent Mode, use uma sessão por fatia. As fichas F00–F16 estão em `docs/slices/`.
