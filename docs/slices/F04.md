# F04 — Primeiro ciclo de cultivo

**Dependência:** F03. **Resultado:** ciclo plantar → cuidar → avançar dias → colher.

Adicionar uma cultura ficcional, semente, estado de crescimento abstrato, cuidado de jogo e colheita. Dados de crescimento são números de balanceamento fictícios, sem orientação para cultivo real. Antes de F05, a colheita pode ir a um contador simples e explícito.

**Aceite:** apenas terreno válido aceita semente; o crescimento ocorre uma vez por dia; a colheita só ocorre no estado pronto; nenhum item é duplicado por toque ou transição. Testar clima neutro, sequência de dias e carregamento de cena.
